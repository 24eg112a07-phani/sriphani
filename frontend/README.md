# ⚡ QuizPulse Elite — Frontend Client

The complete frontend single-page web app for QuizPulse Elite with dark/light mode, Web Audio synthesizer, canvas certificates, and custom quiz builder.

---

## 🚀 Running Locally

Just open `index.html` in any web browser, or serve it using any static server:
```bash
npx serve .
```

---

## 🌐 1-Click Deployment

- **Netlify**: Drag & drop the `frontend` folder directly to [app.netlify.com/drop](https://app.netlify.com/drop).
- **Vercel**: Run `npx vercel` inside this folder.
- **GitHub Pages**: Push this directory to your GitHub repository and activate Pages in Settings.
